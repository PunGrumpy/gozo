Every command accepts the global flags `--json`, `--cwd`, `--yes`, `--non-interactive`, `--no-color`, `--debug` and `--project`. The output below is generated from the binary.

## gozo init

```text
Create gozo.toml (and a Go module if needed) in a directory

Usage: gozo init [OPTIONS] [PATH]

Arguments:
  [PATH]  Directory to initialise. Defaults to the current directory

Options:
      --json             Emit machine-readable JSON on stdout instead of human output
      --name <NAME>      Project name written to gozo.toml. Defaults to the module's last element
  -C, --cwd <DIR>        Run as if started in this directory
      --module <MODULE>  Module path for `go mod init` when there is no go.mod yet
      --cmd <NAME>       Name of the main package to create under cmd/ when there is no go.mod yet [default: api]
  -y, --yes              Answer every prompt with its default
      --force            Overwrite an existing gozo.toml
      --non-interactive  Never prompt; fail instead. Implied when stdin is not a terminal or an agent is detected
      --no-color         Disable colors and symbols. NO_COLOR=1 does the same
  -d, --debug            Show the underlying go/docker/kubectl commands as they run
      --project <NAME>   Project name to use instead of the linked or configured one [env: GOZO_PROJECT=]
  -h, --help             Print help
```

## gozo env

```text
Manage environment variables (ls, add, rm, update, pull, run)

Usage: gozo env [OPTIONS] <COMMAND>

Commands:
  ls      List variables, values masked unless --show-values
  add     Add a variable. The value comes from --value, stdin, or a hidden prompt
  update  Change an existing variable (same as `add --force`)
  rm      Remove a variable
  pull    Write an environment's variables to a dotenv file (default .env.local)
  run     Run a command with an environment's variables injected (no file is written)

Options:
      --json             Emit machine-readable JSON on stdout instead of human output
  -C, --cwd <DIR>        Run as if started in this directory
  -y, --yes              Answer every prompt with its default
      --non-interactive  Never prompt; fail instead. Implied when stdin is not a terminal or an agent is detected
      --no-color         Disable colors and symbols. NO_COLOR=1 does the same
  -d, --debug            Show the underlying go/docker/kubectl commands as they run
      --project <NAME>   Project name to use instead of the linked or configured one [env: GOZO_PROJECT=]
  -h, --help             Print help
```

## gozo tool

```text
Manage tools declared with `tool` directives in go.mod

Usage: gozo tool [OPTIONS] [COMMAND]

Commands:
  ls        List tools declared in go.mod (default)
  add       Add a tool: `go get -tool <pkg[@version]>`
  rm        Remove a tool: `go get -tool <pkg>@none`
  run       Run a tool: `go tool <path> [ARGS...]`
  outdated  Show tool modules that have a newer version (needs the network)
  update    Update one tool, or all, to `@latest`

Options:
      --json             Emit machine-readable JSON on stdout instead of human output
  -C, --cwd <DIR>        Run as if started in this directory
  -y, --yes              Answer every prompt with its default
      --non-interactive  Never prompt; fail instead. Implied when stdin is not a terminal or an agent is detected
      --no-color         Disable colors and symbols. NO_COLOR=1 does the same
  -d, --debug            Show the underlying go/docker/kubectl commands as they run
      --module <DIR>     Module directory to operate on (default: the module containing the current directory, else the root module)
      --project <NAME>   Project name to use instead of the linked or configured one [env: GOZO_PROJECT=]
  -h, --help             Print help
```

## gozo test

```text
Run tests across every module with a unified summary

Usage: gozo test [OPTIONS] [PACKAGES]... [-- <GO TEST ARGS>...]

Arguments:
  [PACKAGES]...      Packages to test, e.g. `./internal/...`. Default: `./...` in every module
  [GO TEST ARGS]...  Extra arguments passed to `go test` verbatim (after `--`)

Options:
      --json             Emit machine-readable JSON on stdout instead of human output
      --run <PATTERN>    Only run tests matching this regexp (`go test -run`)
  -C, --cwd <DIR>        Run as if started in this directory
      --race             Enable the race detector
      --cover            Enable coverage analysis
  -y, --yes              Answer every prompt with its default
      --non-interactive  Never prompt; fail instead. Implied when stdin is not a terminal or an agent is detected
      --short            Tell long-running tests to shorten their run
      --no-color         Disable colors and symbols. NO_COLOR=1 does the same
  -v, --verbose          Print every test name, not just packages
  -d, --debug            Show the underlying go/docker/kubectl commands as they run
      --failfast         Stop after the first test failure
      --project <NAME>   Project name to use instead of the linked or configured one [env: GOZO_PROJECT=]
  -h, --help             Print help
```

## gozo build

```text
Build every main package with version info injected

Usage: gozo build [OPTIONS] [CMDS]...

Arguments:
  [CMDS]...  Main packages to build: a name (`api`), a path (`./cmd/api`) or an import path. Default: gozo.toml `build.cmds`, else every main package

Options:
      --json                  Emit machine-readable JSON on stdout instead of human output
  -o, --output <DIR>          Output directory (default: gozo.toml `build.output`, else `dist`)
  -C, --cwd <DIR>             Run as if started in this directory
      --os <GOOS>             Target operating system (GOOS)
      --arch <GOARCH>         Target architecture (GOARCH)
  -y, --yes                   Answer every prompt with its default
      --non-interactive       Never prompt; fail instead. Implied when stdin is not a terminal or an agent is detected
      --target <GOOS/GOARCH>  Cross-compile target as GOOS/GOARCH; repeat for several
      --no-color              Disable colors and symbols. NO_COLOR=1 does the same
      --version <V>           Version string for `main.version` (default: `git describe`, else `dev`)
  -d, --debug                 Show the underlying go/docker/kubectl commands as they run
      --ldflags <FLAGS>       Extra `-ldflags`, appended after the ones gozo injects
      --no-trimpath           Do not pass `-trimpath`
      --project <NAME>        Project name to use instead of the linked or configured one [env: GOZO_PROJECT=]
  -h, --help                  Print help
```

## gozo deploy

```text
Build and deploy to the linked target

Usage: gozo deploy [OPTIONS]

Options:
      --json                   Emit machine-readable JSON on stdout instead of human output
      --prod                   Deploy to production instead of preview
  -C, --cwd <DIR>              Run as if started in this directory
      --target <TARGET>        Deploy to this target instead of the linked one (docker or kubernetes)
  -e, --env <KEY=VALUE>        Runtime variable for the deployed process, on top of `gozo env`. Repeatable
  -y, --yes                    Answer every prompt with its default
  -b, --build-env <KEY=VALUE>  Build argument passed to `docker build --build-arg`. Repeatable
      --non-interactive        Never prompt; fail instead. Implied when stdin is not a terminal or an agent is detected
      --no-color               Disable colors and symbols. NO_COLOR=1 does the same
      --tag <TAG>              Image tag. Defaults to the short git SHA (plus `-dirty`) or a timestamp
  -d, --debug                  Show the underlying go/docker/kubectl commands as they run
  -f, --force                  Rebuild the image without the build cache
      --no-wait                Return as soon as the rollout is requested instead of waiting for it
      --project <NAME>         Project name to use instead of the linked or configured one [env: GOZO_PROJECT=]
      --logs                   Stream the underlying build and rollout output
      --dry-run                Build the image but do not start or roll out anything
  -m, --meta <KEY=VALUE>       Free-form metadata recorded with the deployment. Repeatable
  -h, --help                   Print help
```
